# Pokój Zosi

Static comparison of five Biscuit Arch room concepts, dated 28 September–20 October 2026.

- 48 visualizations, model views and plans, visually grouped by viewing direction.
- Per-project galleries, two-project comparison, a comparison slider and a five-project overview.
- 34 shopping proposals transcribed from the corresponding designer emails, with original links and explicit unknowns.
- Shopping checkboxes persist only in the visitor's local browser.
- Source images were resized to a maximum of 1800 pixels and encoded as WebP. The original PAX PDF is included.

The source material consists of designer attachments and product suggestions. Email addresses, forwarded correspondence, contact numbers and private Gmail links are excluded. Shopping links and availability have not been revalidated.

Deploy by placing this directory at `pokoj-zosi/` in the root of the existing `CapedHero/ai-public` GitHub Pages source branch (`main`). Existing root pages remain intact. No build step or dependencies are needed.

Visualizations and interior design: Biscuit Arch / Ewelina Skiterska. Viewpoint groups are approximate; source cameras differ between concepts.
